## Featured Projects

### AI / ML Engineering

| Project | Description |
|---|---|
| [**PocketRad — Radiology Education with MedGemma + MedSigLIP**](https://github.com/EmilioMonteLuna/PocketRad-Radiology-Tutor-using-MedGemma-MedSigLIP) | Retrieval-augmented chest X-ray education tool built on Google's HAI-DEF models. Upload a CXR, retrieve 3 visually similar confirmed cases via MedSigLIP, and get a grounded explanation generated by MedGemma 4B. Streamlit UI, trained/evaluated on the Indiana University CXR dataset (7,470 chest X-rays). Educational use only, not for clinical diagnosis. |
| [**PopIn Event Networking AI**](https://github.com/EmilioMonteLuna/PopInEventNetworkingAIProj) | NLP-driven networking recommendation engine that connects like-minded attendees at events. |
| [**Traffic Analysis with PyTorch**](https://github.com/EmilioMonteLuna/Traffic_Pytorch) | Deep learning model analyzing and predicting real-world traffic patterns. |
| [**Fuel Economy Linear Regression**](https://github.com/EmilioMonteLuna/Fuel_Economy_LinRegression) | Regression model predicting vehicle fuel efficiency from vehicle specs. |

### Data Engineering

| Project | Description |
|---|---|
| [**End-to-End DE — Global Retail**](https://github.com/EmilioMonteLuna/End-to-End-DE-Global-Retail) | Full data engineering pipeline (Databricks + Delta Lake on AWS) for a simulated multinational retailer, with automated ETL, data quality checks, and Power BI dashboards. |
| [**Music Pipeline Project**](https://github.com/EmilioMonteLuna/Music-pipeline-Project) | Medallion-architecture pipeline (Bronze/Silver/Gold) ingesting data from the Last.fm, MusicBrainz, and Genius APIs. Mage orchestrates ingestion into raw JSON on GCS, BigQuery holds the cleaned Silver tables, and dbt builds the business-ready Gold views. Infrastructure is provisioned with Terraform, containerized with Docker, and the Gold layer powers a live Looker Studio dashboard answering questions on top artists, streaming vs. lyric-search interest, and genre/country trends. |
| [**DE-5day**](https://github.com/EmilioMonteLuna/DE-5day) | Production-style medallion architecture pipeline (Bronze/Silver/Gold) on Databricks processing the TPC-H benchmark dataset (8 tables, ~43M rows total) through serverless compute. Features layer isolation, SCD Type 1 change handling, automated data-quality expectations in Silver, and a single orchestrated job running all three layers in sequence. |
| [**Food Marketing Data Analysis**](https://github.com/EmilioMonteLuna/FoodMarketing_DA_Project) | Data-driven case study on food industry marketing challenges using Python analytics and visualization. |
